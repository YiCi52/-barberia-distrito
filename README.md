# Barbería Distrito

Landing page para una barbería en Bogotá. HTML/CSS/JS puros, mobile-first, sin dependencias.

## Estructura

- `index.html` — todo el sitio en un solo archivo (estilos y script inline)

## Stack

- HTML + CSS + JavaScript vanilla
- Google Fonts (Bebas Neue + Inter)
- Sin frameworks, sin build step

## Deploy

GitHub Pages: el sitio sirve directo desde la rama `main`. Una vez activado en Settings → Pages, queda en `https://<usuario>.github.io/barberia-distrito/`.

## Cambios típicos

- **Número de WhatsApp**: buscar `573001234567` en `index.html` (aparece en 3 lugares) y reemplazar por el número real.
- **Precios / servicios**: sección `<!-- SERVICIOS -->` en `index.html`.
- **Dirección y horarios**: sección `<!-- AGENDAR -->`, dentro de `.info-list`.
